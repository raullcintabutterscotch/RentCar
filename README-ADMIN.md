# Catatan halaman admin

Petunjuk instalasi, role, alur pembayaran, penjadwalan denda/pengingat, dan pengujian tersedia di `README-INSTALLASI.md`.

Setiap halaman admin menghasilkan struktur sidebar melalui kode layout yang ada di `config/kendaraan_helper.php`; tidak ada ketergantungan ke `admin/partials/sidebar.php`. Akses laporan dibatasi di sisi server untuk role admin.
